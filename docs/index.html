Dependency-free tiny validators

Japanese form validation,
made tiny.

郵便番号、携帯電話番号、日本の電話番号っぽい形式、全角カタカナ、全角文字を判定する小さな TypeScript ライブラリです。

Try demo Install 
import {
  isPostalCodeJP,
  isMobilePhoneJP,
} from "ja-form-validators"

isPostalCodeJP("150-0001")
// true

isMobilePhoneJP("090-1234-5678")
// true

Small scope

日本向けフォームでよく使う validator だけに絞っています。

No normalization

入力値は変換しません。判定だけを行うので責務が明確です。

TypeScript ready

TypeScript 対応。フロントエンドでもバックエンドでも使えます。

Live demo

入力値を変更すると、各 validator の結果がリアルタイムで変わります。

「問い合わせ先（固定・携帯）」では、固定電話と携帯電話だけを受け付けます。

Install

npm からインストールして使えます。

npm install ja-form-validators

API

v0.3.0 の判定関数

isPostalCodeJP

日本の郵便番号を判定します。

150-0001 / 1500001

isMobilePhoneJP

070 / 080 / 090 から始まる携帯番号を判定します。

090-1234-5678

isPhoneNumberJP

日本の電話番号っぽい形式を軽量に判定します。

03-1234-5678

isStrictPhoneNumberJP

kinds で受け付ける電話番号の種類を選べます。

{ kinds: ["landline", "mobile"] }

isLandlinePhoneJP

固定電話の番号と市外局番に合った区切りを確認します。

03-1234-5678 / 0312345678

isKatakana

全角カタカナ、長音、中黒、空白を許可します。

タナカ タロウ

isFurigana

全角カタカナを1文字以上含む氏名のフリガナを判定します。

ジョー・ヤマダ

isZenkaku

空文字や表示可能な半角ASCIIを弾きます。半角カタカナも通ります。

山田太郎

Design policy

正規化、整形、住所解析、メール検証は行いません。

CDN

npm公開後は unpkg や jsDelivr から ESM として読み込めます。

https://unpkg.com/ja-form-validators@0.3.0/dist/index.js 
<script type="module">
  import { isPostalCodeJP } from "https://unpkg.com/ja-form-validators@0.3.0/dist/index.js"

  console.log(isPostalCodeJP("150-0001"))
</script>

Works with normalize-ja-input

全角数字やハイフン表記のゆれを受け付けるには、判定前に normalize-ja-input で入力を整えます。 

import { normalizeJaInput } from "normalize-ja-input"
import { isStrictPhoneNumberJP } from "ja-form-validators"

const value = normalizeJaInput("０９０ー１２３４ー５６７８")

isStrictPhoneNumberJP(value)
// true
