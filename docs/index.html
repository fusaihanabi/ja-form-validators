Japanese form validation, made tiny.

郵便番号、電話番号、フリガナ、全角文字を判定する、依存ゼロの TypeScript ライブラリです。

Try demo Install 
import {
  isPostalCodeJP,
  isMobilePhoneJP,
} from "ja-form-validators"

isPostalCodeJP("150-0001")
// true

isMobilePhoneJP("090-1234-5678")
// true

Small scope

日本向けフォームでよく使う validator だけに絞っています。

No normalization

入力値は変換しません。判定だけを行うので責務が明確です。

TypeScript ready

TypeScript 対応。フロントエンドでもバックエンドでも使えます。

Live demo

入力値を変更すると、各 validator の結果がリアルタイムで変わります。

固定電話または携帯電話の国内表記と +81 表記に対応しています。

Install

npm からインストールして使えます。

npm install ja-form-validators

API

v1.7.1 の判定関数

isPostalCodeJP

日本の郵便番号を判定します。

150-0001 / 1500001

validatePostalCodeJP

理由コードと、設定に応じて数字の桁数や修正箇所を返します。

{ includeDetails: true }

isMobilePhoneJP

060・070・080・090 の携帯番号を判定します。060 の次の数字は 1〜9 が対象です。

060-1234-5678

isPhoneNumberJP

日本の電話番号っぽい形式を軽量に判定します。

03-1234-5678

isStrictPhoneNumberJP

kinds で番号の種類、format で表記を選べます。kindMatching で種類の判定方法を切り替えられます。

{ kinds: ["landline", "mobile"], format: "either" }

validateStrictPhoneNumberJP

理由コードと、設定に応じて形式を直す手がかりを返します。

{ ok: false, reason: "format_not_allowed" }

isLandlinePhoneJP

固定電話の番号と市外局番に合った区切りを確認します。

03-1234-5678 / 0312345678

isKatakana

全角カタカナ、長音、中黒、空白を許可します。

タナカ タロウ

isFurigana

全角カタカナを1文字以上含むフリガナを判定します。NFC で濁点・半濁点を合成できます。

{ normalization: "NFC" }

validateFurigana

フリガナを判定し、フォームの案内に使える理由コードを返します。

{ ok: false, reason: "invalid_character" }

isZenkaku

空文字や表示可能な半角ASCIIを弾きます。半角カタカナと制御文字の拒否も設定できます。

{ rejectControlCharacters: true }

validateZenkaku

理由コードと、設定に応じて問題のある文字と位置を返します。

{ includeInvalidCharacter: true }

Design policy

正規化、整形、住所解析、メール検証は行いません。

CDN

どちらの CDN からでも、npm で公開されたパッケージを ES モジュールとして読み込めます。

unpkg

<script type="module">
  import { isPostalCodeJP } from
    "https://unpkg.com/ja-form-validators/dist/index.js"

  console.log(isPostalCodeJP("150-0001"))
</script>

jsDelivr

<script type="module">
  import { isPostalCodeJP } from
    "https://cdn.jsdelivr.net/npm/ja-form-validators/dist/index.js"

  console.log(isPostalCodeJP("150-0001"))
</script>

Works with normalize-ja-input

全角数字やハイフン表記のゆれを受け付けるには、判定前に normalize-ja-input で入力を整えます。 

import { normalizeJaInput } from "normalize-ja-input"
import { isStrictPhoneNumberJP } from "ja-form-validators"

const value = normalizeJaInput("０９０ー１２３４ー５６７８")

isStrictPhoneNumberJP(value)
// true
